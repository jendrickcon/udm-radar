## Contract keys used in the matrix

- **W**: pooled recorded-grade weighted mean = Σ(canonical eligible final point × positive integer units) / Σ(eligible units), using computeWeightedGWA. Excludes numeric zero and all textual/missing grades under the preserved GWA contract. This is not automatically the arithmetic mean of Student GWAs or a subject outcome mean including zero.
- **R**: distinct recorded grades.id slots; Student n is distinct Students in those rows. Entirely absent enrollments cannot be inferred. Missing denominator returns unavailable, never zero.
- **T**: latest selected recorded term, with school-year/semester labels. Earlier comparison retains non-period filters; selected semester remains fixed across earlier years. Assignment/section filters apply only to verified current configured-term records.
- **S**: role-scoped existing support cases/referrals under selected parent-case academic year/semester and status; subject/section/Faculty/year/decision attribution uses matching recorded referrals. This is not an arbitrary created_at date-window filter.
- **U/I/B**: tests/unit/post_defense_analytics_test.php; tests/integration/post_defense_analytics_test.php; tests/browser/post-defense-analytics.spec.js. These are actual files; current execution evidence is separate from canonical planned filenames.
- **Roles**: Student own only; Administrator active cohort; Faculty current own assigned subject/section grades and own referrals/actions. Small groups are available only within these existing authorized roles; no public output, identities in aggregate payload, suppression/anonymous-reidentification guarantee or faculty rankings are claimed.
